🔧 ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК:

→ Используйте: python вместо python3

→ Выполните: chmod +x install_beget.sh

ОШИБКА: "Module not found"
→ Выполните:
  cd ~/fluoxeofers
  source venv/bin/activate
  pip install -r requirements.txt

БОТ НЕ ОТВЕЧАЕТ:
→ Проверьте:
  1. Бот запущен? (screen -r telegram_bot)
  2. Токен правильный? (cat .env)
  3. Бизнес-режим включен?
