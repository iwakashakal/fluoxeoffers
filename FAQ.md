# Часто задаваемые вопросы (FAQ)

## 🤔 Общие вопросы

### Как запустить бота?

**Windows:**
Просто дважды кликните на файл `start.bat`

**Другие ОС:**
```bash
pip install -r requirements.txt
python bot.py
```

### Где взять токен бота?

1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/BotFather)
3. Отправьте `/newbot`
4. Следуйте инструкциям
5. Скопируйте полученный токен

### Как включить бизнес-режим?

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/mybots`
3. Выберите вашего бота
4. Bot Settings → Business Mode → Enable

⚠️ **Важно**: Без бизнес-режима бот не сможет читать сообщения в чатах!

## 🔧 Настройка

### Как добавить список разрешенных пользователей?

Отредактируйте файл `.env`:
```env
ALLOWED_USERS=123456789,987654321,555666777
```

Чтобы узнать свой ID:
1. Напишите боту [@userinfobot](https://t.me/userinfobot)
2. Он пришлет ваш ID

### Бот не реагирует на сообщения в чате

**Проверьте:**
1. ✅ Включен ли бизнес-режим в BotFather
2. ✅ Добавлен ли бот в чат
3. ✅ Есть ли у бота права на чтение сообщений
4. ✅ Правильно ли установлен токен в `.env`

### Как отключить автоматическое закрепление?

Отредактируйте `config.py`:
```python
AUTO_PIN_OFFERS = False
```

### Как изменить время действия оффера?

Отредактируйте `config.py`:
```python
OFFER_EXPIRY_TIME = 60  # 60 минут вместо 55
```

## 💬 Использование

### Какой формат оффера правильный?

**Правильные форматы:**
```
700 https://t.me/nft/IceCream-38973 gram
500 https://t.me/nft/Socks-12345 stars
1000 https://t.me/nft/Gift-999
```

**Неправильные форматы:**
```
gram 700 https://t.me/nft/IceCream-38973  ❌ (валюта в начале)
700 IceCream gram  ❌ (нет ссылки)
https://t.me/nft/IceCream-38973  ❌ (нет суммы)
```

### В чем разница между GRAM и Stars?

- **💎 GRAM** - указывайте `gram` в конце
- **⭐ Stars** - указывайте `stars` или ничего не указывайте

Пример:
```
700 https://t.me/nft/Gift-123 gram  → показывается 💎
700 https://t.me/nft/Gift-123 stars → показывается ⭐
700 https://t.me/nft/Gift-123       → показывается ⭐ (по умолчанию)
```

### Как отменить оффер?

1. Отправьте команду `/cancel` боту в личные сообщения
2. Если офферов несколько, выберите нужный
3. Подтвердите отмену

⚠️ Отменить можно только **свои** офферы со статусом `pending`

### Как посмотреть активные офферы?

Отправьте команду `/myoffers` боту в личные сообщения

### Что делать если оффер принят, но подарок не получен?

1. Продавец должен нажать кнопку "Я передал(а)" **только после реальной передачи**
2. Покупатель получит уведомление
3. Покупатель проверяет подарки в Telegram
4. Если подарок получен - нажимает "Подтвердить получение"
5. Если нет - связывается с продавцом напрямую

## 🛠️ Ошибки и решения

### Ошибка: "Доступ запрещён"

**Причина**: Ваш ID не в списке разрешенных пользователей

**Решение**: 
1. Узнайте свой ID через [@userinfobot](https://t.me/userinfobot)
2. Добавьте в `.env`:
```env
ALLOWED_USERS=ваш_id
```
3. Перезапустите бота

### Ошибка: "Не удалось закрепить сообщение"

**Причина**: У бота нет прав администратора

**Решение**: 
1. Дайте боту права администратора в чате
2. ИЛИ отключите автозакрепление в `config.py`

### Ошибка: "Оффер не найден"

**Причина**: Бот был перезапущен и потерял данные из памяти

**Решение**: 
- Это нормальное поведение
- После перезапуска старые офферы не сохраняются
- В будущем можно добавить сохранение в базу данных

### Бот удаляет сообщения, но не создает карточку

**Причина**: Недостаточно прав или ошибка в формате

**Решение**:
1. Проверьте права бота
2. Проверьте формат оффера
3. Посмотрите логи в консоли

### Ошибка: "Invalid token"

**Причина**: Неправильный токен бота

**Решение**:
1. Проверьте токен в `.env` файле
2. Токен должен быть в формате: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
3. Скопируйте токен заново из BotFather

## 🎯 Продвинутое использование

### Можно ли добавить свои тексты сообщений?

Да! Отредактируйте файл `config.py`, раздел `MESSAGES`

### Можно ли сохранять офферы в базу данных?

В текущей версии офферы хранятся в памяти и теряются при перезапуске.

Для сохранения в БД нужно добавить:
1. SQLite/PostgreSQL/MongoDB
2. Модуль для работы с БД
3. Миграции данных при запуске

Это можно реализовать как дополнительную функцию.

### Можно ли добавить статистику?

Да, можно добавить:
- Количество офферов за период
- Средняя сумма офферов
- Самые популярные NFT
- Процент принятых/отклоненных

Для этого нужно добавить БД и модуль статистики.

### Как добавить уведомления администратору?

Добавьте в `.env`:
```env
ADMIN_ID=ваш_telegram_id
```

И измените код для отправки уведомлений админу при каждой сделке.

## 🔐 Безопасность

### Безопасно ли указывать токен в .env?

Да, если:
1. ✅ Файл `.env` в `.gitignore`
2. ✅ Не публикуете код с токеном
3. ✅ Не даете доступ к серверу посторонним

### Может ли кто-то украсть токен?

Токен безопасен если:
- Не выкладывать его публично
- Не коммитить в Git
- Использовать безопасный сервер

### Что делать если токен скомпрометирован?

1. Откройте [@BotFather](https://t.me/BotFather)
2. `/mybots` → выберите бота → API Token
3. Нажмите "Revoke current token"
4. Обновите `.env` с новым токеном

## 📱 Telegram ограничения

### Почему бот не видит сообщения в больших группах?

Telegram ограничивает ботов в группах >200 участников без специальных прав.

**Решение**: Свяжитесь с [@BotSupport](https://t.me/BotSupport) для снятия ограничений.

### Сколько сообщений можно отправлять в минуту?

Telegram лимиты:
- ~30 сообщений в секунду в разные чаты
- ~20 сообщений в секунду в один чат
- При превышении - временный бан (от 1 минуты до нескольких часов)

### Можно ли использовать бота в каналах?

Нет, бот работает только в:
- Личных чатах (для команд)
- Группах (для обработки офферов)
- Супергруппах (для обработки офферов)
