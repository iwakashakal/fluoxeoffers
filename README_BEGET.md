# 🎁 Telegram NFT Offers Bot - Версия для Beget

> Полнофункциональный бот для обработки офферов на NFT подарки

---

## ⚡ Экспресс-установка

### 1. Загрузите файлы на Beget
- FTP: `ваш_логин.beget.tech`
- Папка: `/home/ваш_логин/fluoxeofers/`

### 2. Откройте SSH терминал
- [Панель Beget](https://cp.beget.com) → SSH/SFTP → Открыть терминал

### 3. Установите бота
```bash
cd ~/fluoxeofers
chmod +x *.sh
./install_beget.sh
```

### 4. Запустите
```bash
screen -S telegram_bot
./start_beget.sh
# Нажмите Ctrl+A, затем D
```

✅ **Готово!** Бот работает 24/7

## 💬 Как это работает

### Покупатель пишет продавцу:
```
700 https://t.me/nft/IceCream-38973 gram
```

### Бот создаёт карточку:
```
╭─────────────────╮
│  Telegram NFT Gift  │
╰─────────────────╯

🎁 IceCream #38973
💰 Предлагает Вам 700 💎

[❌ Отклонить] [✅ Принять]
```

### Продавец принимает → получает инструкции → передаёт подарок → нажимает "Я передал(а)" → покупатель подтверждает → ✅ Сделка завершена!
