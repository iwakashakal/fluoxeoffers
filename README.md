# Telegram Бот для Офферов на NFT Подарки

## 🚀 Быстрый старт

### Windows
1. Дважды кликните на файл `start.bat`
2. Следуйте инструкциям на экране

### Вручную
```bash
# Установите зависимости
pip install -r requirements.txt

# Создайте .env файл
copy .env.example .env

# Отредактируйте .env и добавьте токен бота

# Запустите
python bot.py
```

## Описание
Этот бот позволяет покупателям отправлять офферы продавцам на NFT подарки через Telegram.

## Функционал
- ✅ Обработка офферов в формате: `сумма ссылка_на_NFT [gram|stars]`
- ✅ Автоматическое форматирование сообщений с кнопками
- ✅ Кнопки "Принять" и "Отклонить"
- ✅ Автоматическое закрепление сообщений
- ✅ Уведомления покупателю о передаче подарка
- ✅ Поддержка валют: GRAM (💎) и Stars (⭐)

## Установка

### 1. Установите Python
Убедитесь, что у вас установлен Python 3.8 или новее.

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Создайте бота в BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен
4. **ВАЖНО:** Включите бизнес-режим для бота:
   - Отправьте `/mybots` в BotFather
   - Выберите вашего бота
   - Выберите "Bot Settings" → "Business Mode" → "Enable"

### 4. Настройте бота

Откройте файл `bot.py` и замените:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
```
на ваш реальный токен от BotFather.

Опционально: добавьте ID пользователей, которым разрешен доступ:
```python
ALLOWED_USERS = [123456789, 987654321]  # Замените на реальные ID
```

Если оставить список пустым `[]`, доступ будет у всех.

## Запуск

## Использование

### Для покупателя:

1. Запустите бота командой `/start`
2. Отправьте продавцу сообщение в формате:
   ```
   700 https://t.me/nft/IceCream-38973 gram
   ```
   или
   ```
   500 https://t.me/nft/SockGift-12345 stars
   ```

3. Доступные команды:
   - `/start` - Начать работу с ботом
   - `/help` - Показать справку
   - `/myoffers` - Посмотреть активные офферы
   - `/cancel` - Отменить активный оффер

### Для продавца:

1. Когда покупатель отправит оффер, бот автоматически:
   - Удалит оригинальное сообщение
   - Создаст красивую карточку с офером
   - Добавит кнопки "Отклонить" и "Принять"
   - Закрепит сообщение

2. При нажатии "Принять":
   - Появится инструкция по передаче подарка
   - Кнопка "Я передал(а)"

3. При нажатии "Я передал(а)":
   - Покупатель получит уведомление о передаче
   - Появится кнопка подтверждения получения

4. Когда покупатель подтвердит получение:
   - Сделка завершится
   - Сообщение открепится автоматически

## Формат офферов

```
<сумма> <ссылка_на_NFT> [gram|stars]
```

**Примеры:**
- `700 https://t.me/nft/IceCream-38973 gram` - оффер в GRAM (💎)
- `500 https://t.me/nft/Socks-12345 stars` - оффер в Stars (⭐)
- `1000 https://t.me/nft/Gift-999` - по умолчанию Stars (⭐)

## Примечания

1. **Бизнес-режим обязателен**: Без него бот не сможет работать как чат-бот и отслеживать сообщения.

2. **Права администратора**: В некоторых чатах боту могут потребоваться права администратора для закрепления сообщений.

3. **Ограничения**: Бот работает только в чатах, где он добавлен и имеет необходимые права.

## Устранение неполадок

**Бот не видит сообщения в чате:**
- Проверьте, включен ли бизнес-режим в BotFather
- Убедитесь, что бот добавлен в чат
- Проверьте, что у бота есть права на чтение сообщений

**Не закрепляются сообщения:**
- Дайте боту права администратора в чате
- Или отключите закрепление, закомментировав строки с `pin_chat_message`

**Ошибка токена:**
- Убедитесь, что вы правильно скопировали токен из BotFather
- Токен должен быть в формате: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
